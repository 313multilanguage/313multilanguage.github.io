# Apprendre le français — اپ یادگیری الفبای فرانسوی

یک صفحه‌ی HTML تک‌فایله برای یاد دادن الفبای فرانسوی + کلمات پایه، با صدای ضبط‌شده.
مناسب کسی که فارسی را می‌فهمد ولی خوانده نمی‌تواند: هر کلمه هم **تلفظ فرانسوی** دارد هم **معنی فارسی با صدا**.

**آدرس آنلاین:** https://313multilanguage.github.io/french/

## ساختار
- `index.html` — خودِ اپ. صداها را از `audio/` روی همین سایت می‌خواند.
- `generate_voices.py` — اسکریپت ساختِ صداها با OpenAI (روی ویندوز اجرا شود).
- `audio/fr/*.mp3` — تلفظ فرانسوی (حروف، حروف ویژه، کلمات).
- `audio/fa/*.mp3` — معنی فارسی کلمات.

## ساختِ صداها (یک‌بار)
۱. `python -m pip install openai`
۲. کلید OpenAI را در `generate_voices.py` (متغیر `API_KEY`) یا در محیط `OPENAI_API_KEY` بگذار.
۳. `python generate_voices.py`  → پوشه‌ی `audio/` ساخته می‌شود.
۴. پوشه‌ی `audio/` را به این ریپو (زیر `french/`) پوش کن.

نام فایل‌ها در اسکریپت و در `index.html` باید یکی بماند (A.mp3…Z.mp3، s01…s15، w01…w20).
